# algo-solutions

A collection of algorithmic problem solutions implemented in Java.

## Tech Stack

- Java
- Maven
- JUnit 4

## Project Structure

```
src/
  main/java/online/petrenko/   # Solution implementations
  test/java/online/petrenko/   # Unit tests
```

## Build & Run

```bash
# Build the project
mvn package

# Run tests
mvn test
```
